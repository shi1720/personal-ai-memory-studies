# Language-rich extension: stopped and unfinished

The author stopped this separate experiment before it produced a completed
confirmation study. Local model files were subsequently removed. No further
inference is running or scheduled, and the historical prospective protocols
must not be interpreted as instructions or authorization to restart it.

The repository preserves the extension's input-feasibility work, engineering
preflights, prospective protocols, source code, and synthetic tests. These
materials document work performed and planned; they are not new confirmation
findings, empirical validation of the complete design, or evidence that the
paper's scope has expanded.

The completed paper remains the two-domain Coat and MovieLens audit described
in the main README and submission PDFs. Its frozen primary analyses, reported
results, PDFs, and anonymous supplementary artifact are unchanged by this merge.

The public `research/language-rich-extension` branch was merged into `main`
with its commit history preserved. Its later removal as a branch name does not
remove its commits or files. The combined repository's test suite includes
synthetic tests of this unfinished work; passing those tests does not imply
completion of inference or analysis on reserved participants.

Any future continuation would require a new explicit decision, restored model
dependencies, and a fresh review of the recorded scientific and execution
boundaries. This status note makes no claim that such continuation will occur.
