# Execution record

Both independent protocols and their analysis code are published before reserved-user inference. Exact dependencies are hashed in the two lock files. Evaluation accuracy is withheld until all planned calls in both domains finish.

## Fitting-user checks

Coat output-contract checks used three fitting users and four contexts. Phi returned 12/12 valid arrays; Qwen returned 11/12. No accuracy was calculated. These initial reader-only preflights used four concurrent requests.

A subsequent concurrent native-writer check exceeded the local Metal GPU memory limit. Its unfinished files and server logs were retained locally. No reserved-user calls had begun. Both protocols were changed to one worker and the server to one prompt/decode slot. Three fresh sequential native writes completed, with 12/12 valid Qwen readers. This is a resource fix before evaluation, not an accuracy-based retry.

MovieLens acquisition initially rejected the publisher checksum because the parser expected a GNU-style checksum line but received BSD-style MD5 output. The parser now extracts the sole 32-character checksum and verifies the archive before data preparation. No scores or model calls preceded this fix. The first MovieLens preflight command used the inference-server environment, which lacks the client library; it failed before any request. The client uses the existing native-memory environment.

Secondary MSE decomposition and the joint family of ten comparisons were fixed before evaluation. The MovieLens user split and development selection were first generated before adding this secondary diagnostic; their source protocol hash therefore points to that earlier local protocol version. The frozen lock records the final protocol used for inference and analysis. User selection, item selection, prompts, primary contrasts and penalty grid did not change.

Independent validation here means previously unused users and a second data domain. It does not mean an independent institution has replicated the experiment or peer reviewed the paper. A separate calculation recomputes reported metrics without importing the study's metric implementation.

An earlier whole-archive Coat integrity audit reported rating distributions and overlap before the predictive split. Independent users here means held out from predictive model fitting, tuning and scoring; it does not mean the public archive was never descriptively inspected. The final manuscript states this explicitly.
