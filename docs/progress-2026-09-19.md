## What the data audit established

The cleaned S file has 500 questions, including 30 abstention questions. Thirteen
questions repeat a session ID. Direct inspection found the corresponding contents
identical but dates different; none of those repeated IDs is gold evidence.
The loader preserves positional instances instead of silently overwriting them.
The first validator rejected these duplicates; it was revised to record them as
audit findings, while retaining hard failures for malformed parallel arrays.

The S file has 211 histories whose timestamp arrays are not monotonically sorted.
This is a description of the downloaded data, not proof of incorrect answers.
The pilot's recency baseline uses parsed dates, not array position.

Eighty-seven distinct evidence-session contents recur across question records.
Their overlap graph consists of 47 two-question components and 406 singletons.
These are content-overlap groups, not verified real-user groups.

Original session IDs encode whether a session is evidence. Selecting IDs with
the `answer_` prefix exactly recovers every annotated evidence set in the 470
answerable cases. This is a deliberately invalid shortcut, not a model result.
The upstream generation code removes `has_answer` and formats date/content
rather than exposing the original IDs. We are not alleging upstream leakage.
Our allowlisted input loader likewise excludes original IDs and all gold fields.

## Retrieval pilot

BM25 found all required evidence sessions among its top five for 391/470 cases
(83.19%). It found at least one gold session for 455/470 (96.81%). These differ
substantially, so an any-hit metric would overstate full evidence availability.
Newest-first retrieval covered every required session at five for 30/470 (6.38%).

These are custom, untuned, session-level retrieval measurements. They are not
answer accuracy, a reproduction of a paper's reported scores, a new algorithm,
or evidence of ICML-level novelty. They establish an inexpensive comparison that
a more complex system must take seriously. No significance claim is made.
