# Pilot 003 follow-up controls

Exploratory follow-up after seeing Pilot 003. The first audit selected exclusively
or almost exclusively positive events. These controls diagnose that observed
result; they are not independent confirmation.

Use the same twelve journals, plain rendering only, and frozen local model.
Compare three writer instructions on two outcome wordings, for 72 calls:

1. Original important-event writer.
2. Neutral archive role with the same importance criterion.
3. Explicit proportional selection: retain positive and negative outcomes within
   each activity in proportions as close to the original history as the six-event
   budget permits. This is a task-specific control, not a new method.

Wordings: original enjoyed/did not enjoy, and liked/disliked without grammatical
negation. All IDs, dates, activities and outcome labels remain fixed. No extra
details are added. Output remains a six-ID JSON array with the same strict parser,
160-token limit, temperature zero and no retries. The original important/negation
cases are repeated to audit deterministic execution and are not counted as new
independent journals.

Report retained positive fraction, subgroup rate error, activity-order outcome,
format failures and case-level selections for every arm. Compare repeated cases
with the original run. If a simple explicit instruction resolves the bias, report
that directly and reject a generic new-debiasing-method claim. A residual effect
still needs other models and published writers before generalization.
