# Completed confirmation study

The completed manuscript is **Auditing Personal AI Memory with Rating-Preserving Controls**, by Shivam Gupta. It is a research preprint, not a conference submission or externally reviewed publication.

Evaluation inference completed before accuracy analysis. All four run reports have `complete: true`. Every scheduled response was retained without accuracy-based selection, retry, or repair. An invalid reader response receives the predeclared constant-3 prediction. The ten primary contrasts use 10,000 paired-user bootstrap replicates, seed 20260920, with ordinary 95% and family-adjusted 99.5% percentile intervals.

## Primary contrasts

Positive extraction means native memory increases error. Positive association means correct historical assignments help. Positive numerical-reader means ridge has lower error than the full-history language-model reader.

The larger Coat evaluation resolves the development study's inconclusive extraction result in the direction of increased error for the tested pipeline. MovieLens does not confirm the Coat association effect after family adjustment. These are different domains and sampling processes, not a controlled comparison of exposure bias. The Phi Coat numerical-reader contrast is inconclusive, not evidence of equivalence.

The main text reports paired common-valid checks, metric tradeoffs, and costs. Full precision and all per-user summaries are in `results/confirmation-analysis.json` and `results/movie-validation-analysis.json`. Those files are generated by the frozen analyses, not reconstructed from rounded manuscript numbers.

## Output reliability

| Domain | Qwen invalid | Phi invalid |
|---|---:|---:|
| Coat | 3 / 800 | 74 / 800 |
| MovieLens | 12 / 600 | 61 / 600 |

Of 150 invalid arrays, 35 responses terminate at the token limit and 115 fail the parser after normal termination. No reader transport errors occurred. Phi's MovieLens no-history condition has 59 invalid arrays out of 200, compared with one in each history condition. These failures are visible in both the main table and appendix, rather than dropped from the reported population.

The 200 native writer calls generate 2,830 entries. One length-limited writer response produces an empty store. Native writing consumes 1,974,104 tokens. Native-memory reader prompt totals are 20.7% lower for Qwen and 22.3% lower for Phi than full-history prompt totals on Coat, excluding construction. These are token counts, not lifetime cost or latency estimates.

## Computational validation

The separate implementation checks original archives, independently parses responses, checks exact prompt content and system roles, and recomputes continuous metrics with explicit arithmetic. History-only ridge is verified by augmented least squares. It checks 2,400 Coat and 2,200 MovieLens user-system records and all ten primary effect estimates and bootstrap intervals. Maximum continuous-metric discrepancies are 2.043e-14 and 5.773e-15, respectively, below the fixed 1e-10 tolerance.

Exact floating-point pairwise ties can differ between algebraically equivalent solvers. The recorded precision sensitivity retains the original primary arithmetic, checks common near-tie behavior, and discloses strict-solver disagreement rather than changing the metric after scoring. Primary MAE comparisons are unaffected.

The public-summary verifier additionally checks all 5,400 released error rows, including population-assisted supplementary systems, and regenerates bootstrap intervals with a separate batching implementation. This level needs no source archives, models, or raw inference traces. The 110-test suite passes. These checks validate implementation and arithmetic; they do not constitute independent authorship or external peer review.
